# English Major C

English Major C is an experimental programming language intermediary specifying machine instructions, assembly, or virtual-machine operations in precise, verbose, English.

- [T32 operations and examples](docs/t32-operations-and-examples.md) — Instruction fetching, control flow, stack and bit operations, and byte-level examples.
- [T32 branches and hints](docs/t32-branches-and-hints.md) — Exhaustive branch, IT, hint, exception, and breakpoint decoder tables with audit evidence.
- [T32 address formation and data](docs/t32-address-formation-and-data.md) — PC- and SP-relative addressing, literal loads, code/data boundaries, and verification receipts.
- [Assembly-to-English decompilation](docs/assembly-to-english.md) — Requirements for faithful bottom-up English translations of machine code.
