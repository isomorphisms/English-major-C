## Reproduction and independent acceptance

From any directory, run Node with an absolute checkout path:
`node /ABSOLUTE/English-major-C/examples/autogenerated/arm-linked-ledgers/generate.mjs --check`.
For fresh generation pass `--output /ABSOLUTE/FRESH_DIRECTORY`; existing output
is refused. No package installation, compilation or specimen execution occurs.

The pinned ai-ci source in `.github/workflows/fortran-coverage.yml` independently
reads the original Git blobs, readelf sections/mapping symbols/ABI flags and
relocations. It imports no producer code and does not trust the new summaries
as source evidence. It checks all 3,546 ledger entries and rejects 21 targeted
corruptions. A separate unavailable-source case must explicitly report
`MISSING_SOURCE_EVIDENCE`. The exact-head artifact contains source/digest pins
and statuses. This establishes structural ledger acceptance, **not semantic
equivalence**; meaning correctness beyond those structural assertions remains
unverified.

Run the independent checker with an absolute oracle path:
`node /ABSOLUTE/ai-ci/fortran-coverage/check-arm-ledgers.mjs --repository /ABSOLUTE/English-major-C --self-test --receipt /ABSOLUTE/FRESH_RECEIPT.tsv`.
Receipts require clean material paths at the recorded leaf and oracle heads.

## Failure and recovery

Missing pinned Git objects fail with `MISSING_PINNED_SOURCE` (producer) or
`MISSING_SOURCE_EVIDENCE` (oracle). Fetch the named commit from the original
repository, verify both SHA-256 values in `specimens.tsv`, then retry. If the
commit is no longer recoverable, retain that failure and mark the affected
specimen missing; never substitute a rebuild or a different ABI.

Changed bytes, unfamiliar mnemonics, conflicting mapping symbols, new data/ISA
boundaries, stale outputs or changed scope fail closed. Recover the original
blob before regeneration. A genuinely new capture needs its own provenance and
denominator decision. Suppressed zeros are recovered only from the captured
ELF, remain DATA, and do not become invented instructions.

The architecture reference is Arm DDI 0406C.d. The attempted primary PDF fetch
exceeded the retrieval service's size limit; the AAPCS 2025Q1 page fetch was also
unavailable. Those retrieval failures are not semantic evidence. No complete
instruction-by-instruction primary-source verification was attempted or claimed.
The existing A32 machine document and new catalogue supply preliminary reading
only. The bounded semantic-slice follow-up remains open.
