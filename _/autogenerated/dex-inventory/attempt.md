# DEX inventory validation attempt

## Type and effect sketch, written before the program

An opcode byte is a bounded natural number from zero through 255. A catalogue
row contains its identity, official mnemonic, format, version range, validity,
reads, writes, continuation, operand restrictions, exceptions, English prose
and source identities. Inventory order and byte identity are separate facts.

The small pure Idriç slice checks that an ordered list equals the complete
interval. Its desired input is `List Number`, its result is `Bool`, and equality
uses `≟`. The invariant is exact order and exactly one copy of each value.
An omitted, duplicate or out-of-range element must return False. It deliberately
does not parse English, decode DEX instructions or execute their semantics.

The larger source checker needs UTF-8 file I/O, TSV/line handling, SHA-256,
subprocess status, fixture mutation and comparisons with foreign source tables.
Those effects are separate from the pure finite-list predicate.
